# World Cup 2026 Sweepstake Tracker

Live bracket + odds tracker for a 12-player World Cup sweepstake. Each player
owns 4 teams; the site shows the group stage, the knockout bracket, a full
fixture schedule (AEST), and a live odds table — with each team's owner, a seed
number, and green/red arrows as Sportsbet's prices move.

**Live site:** https://pavlova-del.github.io/worldcupbracket/

## How it works
- `docs/` is the static site (vanilla HTML/CSS/JS — no build step).
  - `docs/index.html`, `docs/styles.css`, `docs/app.js`
  - `docs/data/tournament.json` — groups, owners, flag codes, bracket template (static).
  - `docs/data/odds_latest.json` / `odds_prev.json` — odds snapshots; the app diffs
    them for movement arrows.
  - `docs/data/fixtures.json` — match list with kickoff times.
- `scrape_snapshot.py` pulls the live Sportsbet markets (winner + to-reach-round)
  and the fixtures list, writing the JSON above. Reuses `scrape_sportsbet_wc.py`.
- `.github/workflows/deploy.yml` runs the scraper every ~15 minutes, commits the
  refreshed snapshot (so arrows compare against the previous run) and redeploys
  GitHub Pages from `docs/`.

## Run locally
```bash
python3 scrape_snapshot.py            # refresh docs/data/*.json
cd docs && python3 -m http.server 8765
# open http://localhost:8765
```
Deep links: `?view=knockout` / `?view=schedule` open those tabs; `?owner=Zac,Pat`
pre-highlights players; `?tab=players` opens the slip-odds table.

## Notes
- `tournament.json` is generated by `build_tournament.py` (kept out of this repo;
  it scrapes the real 2026 group draw). It changes rarely, so the result is
  committed directly.
- If Sportsbet ever blocks the GitHub Action's cloud IP, run `scrape_snapshot.py`
  on a local machine on a schedule and push `docs/data/*.json` instead — the
  frontend is identical either way.
